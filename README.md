# Blackout for YouTube

**보기 싫은 건 보지 않을 권리.**

Blackout for YouTube는 특정 YouTube 채널의 콘텐츠를 사용자의 화면에서 가리는 Manifest V3 브라우저 확장 프로그램입니다. 서버, 회원가입, 분석 SDK 없이 브라우저 로컬 저장소만 사용합니다.

## v0.1.0 기능

- 채널별 차단
- 홈 / 검색 / 추천 영상 검열
- Shorts 검열
- 커뮤니티 게시물(Posts) 검열
- 검은색 / 블러 / 사용자 지정 이미지 / 완전 숨김
- 무한 스크롤 및 YouTube SPA 탐색 대응
- 차단 목록 JSON 가져오기 / 내보내기
- 모든 설정 `chrome.storage.local` 저장

## 설치

1. 이 저장소를 ZIP으로 내려받아 압축을 풉니다.
2. Chrome 또는 Edge에서 확장 프로그램 관리 페이지를 엽니다.
3. **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
5. 이 프로젝트 폴더를 선택합니다.

## 사용법

YouTube 영상, Shorts, 게시물 카드의 우측 상단에 나타나는 `차단` 버튼을 누르면 해당 채널이 즉시 차단됩니다. 확장 프로그램 팝업 또는 설정 페이지에서 검열 방식을 변경하거나 차단 목록을 관리할 수 있습니다.

## 개인정보

Blackout은 원격 서버를 사용하지 않으며 YouTube 시청 기록이나 차단 목록을 전송하지 않습니다. 사용자 설정은 브라우저 로컬 저장소에만 저장됩니다.

## 주의

YouTube는 DOM 구조를 수시로 변경합니다. 특정 레이아웃에서 차단 버튼이나 검열이 동작하지 않으면 Issue로 알려주세요.
